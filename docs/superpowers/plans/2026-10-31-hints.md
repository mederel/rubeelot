# Ask for a Hint (US-065) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A player at a solo or pass-and-play table can ask which card or bid the Challenging bot would pick, and why, through a read-only endpoint and a "Hint" button.

**Architecture:** `beelot-game` gets `bot/hints.rs`: it asks the Challenging strategy for its choice, then a pure classifier names one reason code. `beelot-server` adds `Table::hint` (local tables only, no version change), `GET /api/tables/{id}/hint` and a `table.hints` flag in the snapshot. The static client shows a button, highlights the card or bid and prints the translated reason.

**Tech Stack:** Rust (axum, serde), vanilla JS in `crates/beelot-server/static/`, Playwright for the browser check.

**Spec:** `docs/superpowers/specs/2026-10-30-hints-design.md`

## Global Constraints

- Local tables only (`TableKind::Local`): solo and pass-and-play. Online tables answer `404` (`AppError::NotFound`).
- The hint always comes from `strategies::for_difficulty(Difficulty::Challenging)`, from the seat's own `PlayView` or `AuctionView`.
- A hint changes nothing: no `version` bump, no SSE event, nothing recorded.
- Any state without a hint to give (no auction or board, trick under review, round over, a bot's turn) is `409` with code `no-hint`.
- Reason codes are `SCREAMING_SNAKE_CASE`; the client translates them. Thirteen reasons: card `LEAD_TRUMPS`, `CASH_MASTER`, `LEAD_LOW`, `GIVE_POINTS`, `KEEP_PARTNERS_TRICK`, `WIN_CHEAPLY`, `THROW_CHEAPEST`, `BEST_FOR_ROUND`; bid `TAKE`, `SUPPORT_PARTNER`, `BID_HAND_VALUE`, `COINCHE`, `PASS_WEAK`.
- "Value" of a card is `bot::rule_based::by_value(trump)`: points under the contract, ties broken by strength.
- New texts exist in English (the key), French (`i18n.js`) and Dutch (`i18n-nl.js`).
- Rate limiting: the existing `/api` limit covers the route; add none.
- Checks before each commit that touches Rust: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test --workspace` (Docker must run for the server's database tests).

## Review Focus

- Tout-atout and sans-atout contracts: the classifier must not panic or claim `LEAD_TRUMPS` where no suit is trump (Task 1).
- A forced play (one legal card, or the last trick): still a card from `legal_cards` with a reason (Tasks 1 and 3).
- Classic second round and upturned-suit acceptance: both are `AuctionDecision::Trump`, and the answer carries the suit so the client can write "Take: strong hand in {suit}" (Tasks 2 and 4).
- Pass-and-play: the hint is for the human whose turn it is, not for seat 0 (Task 5).
- Round result shown, or match complete: `409 no-hint`, not a panic or a stale hint (Task 5).

  - `leading_the_master_of_a_plain_suit_cashes_it`: lead `AS` from `AS 7C 8D` → `CashMaster`.
  - `leading_the_lowest_card_of_a_suit_leads_low`: lead `7D` from `7D KD 8C` → `LeadLow`.
  - `following_a_sure_trick_of_the_partner_gives_points`: trick seat 2 `AS`, seat 3 `7S`; hand `10S 8S 7C`; card `10S` → `GivePoints`.
  - `following_a_partner_who_may_be_beaten_keeps_the_trick`: trick seat 2 `10S`, seat 3 `9S`; hand `7S 8S 7C`; card `7S` → `KeepPartnersTrick`.

  - `discarding_the_cheapest_card_throws_it`: trick seat 3 `AS`; hand `8S 9S`; card `8S` → `ThrowCheapest`.
  - `a_dearer_winner_than_necessary_falls_back`: trick seat 3 `9S`; hand `10S QS 7C`; card `10S` → `BestForRound`.
  - `a_forced_card_behind_an_opponent_is_thrown`: trick seat 3 `AS`; hand `7S 8D`; legal is only `7S`; → `ThrowCheapest`.
  - `no_suit_is_trump_under_sans_atout_or_tout_atout` (`Variant::Contree`): `Trump::NoTrumps`, lead `AH` from `AH 7C` → `CashMaster`; `Trump::AllTrumps`, lead `JH` from `JH 7C` → `CashMaster`, and neither is `LeadTrumps`.

- [ ] **Step 3: Implement `card_reason`.** Build `CardMemory::new(view)`; the current trick leads when `view.current_trick` is empty.
